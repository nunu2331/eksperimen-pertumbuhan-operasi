# Eksperimen Python: Memahami Pertumbuhan Operasi

Program pendamping worksheet mata kuliah Kompleksitas Algoritma. Program membandingkan jumlah operasi pada:

- satu perulangan: `n` operasi atau `O(n)`;
- dua perulangan bersarang: `n x n` operasi atau `O(n^2)`.

## Menjalankan program

```bash
python eksperimen_pertumbuhan_operasi.py
```

Program menampilkan tabel hasil eksperimen di terminal dan menyimpan dua grafik ke folder `hasil/`.
